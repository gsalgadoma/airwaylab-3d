Fuente de datos

Los archivos .vti se procesan en tu navegador y no se cargan al repositorio. Elige únicamente estudios anonimizados y autorizados. La demostración sintética NO es una TC real.

Preparando motor de renderización...

Para convertir TC DICOM a .vti utiliza 3D Slicer o una herramienta de conversión validada. Los valores de ejemplo corresponden a escalas HU solo cuando los datos conservan esa calibración. Un archivo VTI genérico puede tener otras unidades.

Volumen tridimensional

Arrastra para rotar; rueda o pellizca para acercar. La imagen de demostración es un fantoma computacional con densidades sintéticas. No representa una persona. No apto para diagnóstico, mediciones clínicas ni planificación de procedimientos.
